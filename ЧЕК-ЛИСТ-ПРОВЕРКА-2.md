# Чек-лист проверки — правки по итогам визуальной проверки (06.10.2026)

Версия **2.1.0**, сборка от 19:01. Артефакты:

- Portable: `backend\dist\BiziBox.exe`
- Установщик: `installer\dist\installer\BiziBox-Setup-2.1.0.exe`

**Как проверить:** скопируй новый `BiziBox.exe` в тестовую папку (замени старый), удали старый `.env` (чтобы он пересоздался с `ENABLED=False`), запусти приложение, пройди онбординг (на шаге «Прокси/VPN» выбери «Системный VPN» или «Напрямую», ничего не вводя).

Ниже — только то, что изменилось в этой сессии. Проверяй по порядку.

---

## 1. Классификация контакта — единое дерево

- [ ] **Карточка контакта.** *Где:* Контакты → открыть любой контакт → кнопка **«Классифицировать»**. *Ожидание:* открывается «Классификация контакта» — одно дерево: «Другое (без сферы)», затем сферы (Работа / Личное / Каналы / Спам). Сферы с папками раскрываются по клику (шеврон вправо→вниз), внутри — папки и подпапки с отступами.
- [ ] **Нет двух отдельных полей.** В диалоге классификации больше нет двух селекторов «Сфера» + «Папка» — только дерево.
- [ ] **Выбор папки.** Кликнуть по папке → она подсвечивается; «Сохранить» → в карточке показывается сфера и папка.
- [ ] **Выбор «Без папки».** Раскрыть сферу → кликнуть «Без папки» → «Сохранить» → контакт в сфере без папки.
- [ ] **Спам.** Кликнуть «Спам» → папок нет, «Сохранить» → контакт помечается спамом.
- [ ] **Другое.** Кликнуть «Другое (без сферы)» → «Сохранить» → сфера сбрасывается.
- [ ] **Форма создания/редактирования.** *Где:* Контакты → «Создать контакт» (или «Редактировать»). *Ожидание:* блок **«Классификация»** — то же дерево (без select «Сфера»/«Папка»).

## 2. Папки: подпись, рекурсия, разворачивание, «Создать папку»

- [ ] **Нет подписи «системная».** В дереве папок (Контакты/Входящие) у системных папок больше нет серого бейджа «системная» — название папки ничем не перекрывается.
- [ ] **Верхнеуровневая папка → все подпапки.** *Где:* Контакты → в сайдбаре выбрать папку, у которой есть подпапки. *Ожидание:* в списке контактов видны контакты и из самой папки, и из всех её подпапок (рекурсивно).
- [ ] **Развёрнутый блок не сворачивается.** Раскрыть сферу, кликнуть папку/подпапку внутри. *Ожидание:* список папок сферы остаётся раскрытым, выбранная папка подсвечена (видно, где ты находишься).
- [ ] **Кнопка «Создать папку».** *Где:* сайдбар Контактов (заголовок «Контакты») и Входящие (кнопка рядом с «Редактировать папки»). *Ожидание:* вместо голого «+» — кнопка с текстом **«Создать папку»**.
- [ ] **«Другое» в Контактах.** *Где:* сайдбар Контактов, между «Избранное» и сферами. *Ожидание:* пункт **«Другое»**; при клике показываются неклассифицированные контакты (без сферы и без папки).

## 3. Перетаскивание контакта на папку

- [ ] **DnD работает.** *Где:* Контакты. *Как:* взять строку контакта и перетащить её на папку в сайдбаре (именно на строку папки). *Ожидание:* контакт перемещается в эту папку (сфера контакта меняется на сферу папки); после перезапуска закреплено.
- [ ] **Перетаскивание именно взятого контакта.** Взять один контакт, перетащить на папку — перемещается он, а не ранее выбранный в списке.

## 4. Объединение контактов (мерж)

- [ ] **Имя склеивается.** *Где:* Контакты → выделить два контакта → «Объединить» (или форма контакта → «Объединить с контактом» → поиск). *Ожидание:* итоговое имя = оба имени через пробел (например «Иван Петров»), а не одно из них и не «в заметки».
- [ ] **Дополнительные поля сохраняются.** Если у обоих контактов были разные телефон/email/ТГ — они не теряются. *Ожидание:* в карточке объединённого контакта появляется блок **«Другие идентификаторы»** со вторым телефоном/email/ТГ.
- [ ] **Без дублей.** Повторно объединить с контактом с теми же данными → идентификаторы не дублируются.

## 5. Селектор получателя в диалоге

- [ ] **Появляется при 2+ адресах.** *Где:* Входящие → открыть диалог контакта, у которого больше одного адреса (например, TG ID + TG-логин + email, см. «Другие идентификаторы»). *Ожидание:* над строкой ввода ответа появляется **«Получатель:»** с вариантом «По умолчанию (адрес контакта)» и альтернативными адресами.
- [ ] **Один адрес — селектора нет.** Открыть контакт с одним адресом → селектор «Получатель» отсутствует.
- [ ] **Отправка на альтернативный адрес.** Выбрать другой TG-адрес → отправить сообщение → уходит на выбранного получателя. Сменить диалог → селектор снова «По умолчанию».

## 6. Каналы / Спам — загрузка без повторного скачивания

- [ ] **Пустые при входе.** Перезапустить приложение → вкладки «Каналы» и «Спам» пустые (только счётчик), без автозагрузки.
- [ ] **Две кнопки.** На вкладке «Каналы» (и «Спам») теперь две кнопки: **«Загрузить новые»** (синяя) и **«Показать загруженные»** (серая).
- [ ] **«Показать загруженные».** Нажать её → показываются ранее загруженные диалоги из БД, **без** обращения к Telegram.
- [ ] **«Загрузить новые».** Нажать → докачиваются свежие сообщения из Telegram (уже имеющиеся в БД не дублируются).

## 7. Онбординг — кнопка «Далее»

- [ ] **Кнопка на шаге VPN.** На шаге «Прокси/VPN» внизу кнопка теперь **«Далее»** (а не «Пропустить»). На остальных шагах — тоже «Далее».
