# BiziBox — руководство пользователя

BiziBox — личное приложение «сообщения и дела в одном окне». Объединяет Telegram и Email в единый инбокс, ведёт контакты, задачи и календарь, напоминает о делах и днях рождения. Работает локально: все данные хранятся на вашем устройстве в зашифрованной базе, ничего не уходит в облако.

---

## 1. Установка и запуск

### Системные требования

- Windows 10/11 (64-бит)
- 2 ГБ ОЗУ, ~1 ГБ свободного места

### Portable-версия (рекомендуется)

1. Скачайте `BiziBox.exe` со страницы релизов.
2. Поместите файл в любую папку (например, `D:\BiziBox`).
3. Запустите `BiziBox.exe` — окно консоли не появляется, приложение запускается в фоне и само открывает браузер.
4. В системном трее появится иконка **BiziBox**: «Открыть BiziBox» / «Выход».

Все данные создаются рядом с exe: в папке `data\users\<ваш_логин>\` хранятся база, настройки каналов и вложения.

### Запуск из исходного кода

```powershell
# Backend
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --port 7910

# Frontend (второй терминал)
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## 2. Первый запуск и онбординг

При первом запуске откроется мастер настройки из четырёх шагов:

1. **Telegram** — введите логин (любое имя, по нему создаётся ваша папка данных) и, при желании, номер телефона и данные Telegram.
2. **Email** — адрес, пароль, серверы IMAP/SMTP (порты 993/465 по умолчанию).
3. **Прокси** — SOCKS5-прокси, если нужно (например, для Telegram).
4. **Готово** — проверьте данные и завершите настройку.

Логин можно ввести, а каналы подключить позже в разделе «Каналы». Пропустить шаги можно кнопкой «Пропустить» на шаге прокси.

## 3. Разделы приложения

| Раздел | Что делает |
|---|---|
| **Дашборд** | Главная панель: сводка сообщений, задач, контактов, непрочитанные диалоги. |
| **Входящие** | Единый инбокс Telegram и Email: личные сообщения, лента, папки, спам. |
| **Контакты** | Карточки людей и сервисов: типы, папки, заметки, дни рождения, объединение дублей. |
| **Задачи** | Канбан со статусами «новые / в работе / выполнено», дедлайны, повторяющиеся задачи. |
| **Календарь** | Задачи, события и дни рождения; виды «месяц / неделя / день». |
| **Каналы** | Подключение и настройка Telegram и Email. |
| **Архив** | Удалённые контакты, сообщения и задачи. |
| **Настройки** | Тема, уведомления, экспорт/импорт данных. |

Внизу бокового меню — **Справка** (краткая подсказка по разделам) и **Выход** (пройти онбординг заново, данные сохраняются).

## 4. Подключение каналов

### Telegram

1. Откройте **Каналы** → **Подключить Telegram**.
2. Введите номер телефона в формате `+79123456789`.
3. Введите код, который придёт в Telegram (или SMS).
4. Если включена двухфакторная аутентификация — введите пароль.

Вход идёт по вашему номеру телефона. API ID/API Hash принадлежат приложению — их вводить не нужно (либо укажите свои в расширенных настройках).

### Email

1. **Каналы** → **Подключить Email**.
2. Укажите адрес, пароль, IMAP-сервер (входящие) и SMTP-сервер (исходящие).
3. Письма будут подтягиваться в общий инбокс.

## 5. Офлайн-режим и ожидающие сообщения

BiziBox работает и без интернета:

- Скачанные сообщения, контакты и задачи сохраняются локально и доступны офлайн.
- Сообщение, отправленное без связи, не теряется: оно помечается значком **⏳ «ожидает отправки»** и уходит автоматически, как только появится интернет.

Когда есть неотправленные данные, вверху появляется кнопка **«Ожидает: N»**. Нажмите её, чтобы открыть список ожидающих отправки:

- **Изменить** — отредактировать текст сообщения перед отправкой.
- **Отменить** — убрать сообщение из очереди (оно не будет отправлено).

Если отправка не удалась, появится кнопка **«Ошибки: N»**: там можно повторить отдельную запись, повторить все или отбросить неудачные.

## 6. Резервное копирование

В **Настройках**:

- **Экспорт** — скачать все данные одним файлом `bizibox-export-….json`.
- **Импорт** — загрузить ранее сохранённый файл, чтобы восстановить данные.

Рекомендуется регулярно делать экспорт и хранить файл в надёжном месте.

## 7. Настройки

- **Тема** — переключение светлой/тёмной темы.
- **Уведомления** — push-уведомления о новых сообщениях (при поддержке браузером).
- **Экспорт/импорт** — резервное копирование данных (см. выше).

## 8. Установка как PWA на телефон

Откройте приложение в браузере на телефоне (в той же локальной сети) и используйте «Добавить на главный экран» / «Установить приложение». BiziBox поддерживает офлайн-кеш и работает как обычное приложение.

---

## 9. Частые вопросы

**Где хранятся мои данные?**
Локально, рядом с exe: `data\users\<ваш_логин>\`. База зашифрована (Fernet), в облако ничего не отправляется.

**Как сменить пользователя?**
Кнопка **Выход** внизу бокового меню — пройдёте онбординг заново. Данные прежнего логина сохранятся.

**Почему не приходят сообщения?**
Проверьте раздел **Каналы**: канал должен быть подключён (зелёная отметка). Для Telegram в регионах с блокировками включите прокси.

**Как отменить сообщение, отправленное без интернета?**
Нажмите «Ожидает: N» вверху → у нужного сообщения «Отменить».
