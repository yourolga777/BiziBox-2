# Чек-лист проверки BiziBox v2.1.0

Пройдите пункты по порядку. Отмечайте результат: пройдено / ошибка (с описанием).

## 1. Установка и запуск

- [ ] Portable: скопировать `BiziBox.exe` в отдельную папку (например `D:\BiziBox`), запустить двойным кликом.
- [ ] Окно консоли/терминала не появляется — приложение работает в фоне.
- [ ] В системном трее появилась иконка BiziBox (синий квадрат с буквой **B**).
- [ ] Браузер открылся на `http://127.0.0.1:7910` (или на следующем свободном порту `7911`…`7925`, если `7910` занят) в режиме инкогнито.
- [ ] Если одновременно запущен другой инстанс (BiziBox/IziBox) на `7910` — новый экзе не «соскакивает» на чужой порт с чужими данными: он выбирает свободный порт и показывает СВОИ данные.
- [ ] Третий запуск повторно открывает окно приложения, данные не потерялись.

## 2. Онбординг

- [ ] При первом запуске появляется экран приветствия (онбординг), а не пустая страница и не 500.
- [ ] Логин создаётся, после онбординга попадаете в приложение (страница Дашборд или Входящие).
- [ ] Неверные/пустые данные онбординга показывают понятную ошибку, не «500».
- [ ] Рядом с exe появилась папка `data\users\<ваш_логин>\` с файлом базы данных.

## 3. Каналы (Telegram / Email)

- [ ] Страница «Каналы»: можно добавить новое подключение (Telegram / Email).
- [ ] Канал отображается в списке со статусом «подключён» / «отключён».
- [ ] При добавлении Telegram через код подтверждения: код можно ввести, ошибки показываются понятно.

## 4. Входящие и сообщения

- [ ] На странице «Входящие» отображаются полученные сообщения из подключённых каналов.
- [ ] Можно ответить на сообщение и оно уходит в «Отправленные» (Outbox).
- [ ] Сообщение можно отметить прочитанным/непрочитанным, отправить в архив, удалить.
- [ ] Поиск по тексту сообщений находит нужное.
- [ ] Спам-сообщения не приходят во «Входящие» (если контакт помечен как спам).

## 5. Контакты (классификация)

- [ ] Создать контакт: заполнить имя, выбрать **сферу**: Личное / Рабочее / Спам.
- [ ] У контакта можно проставить **типы** (например Клиент, Поставщик, Друг) — больше одного.
- [ ] Управление типами: на странице контактов есть раздел «Типы контактов» — можно создать/переименовать/удалить свой тип.
- [ ] Выбрать контакту **папку** (системную или свою); папки можно создавать с подпапками.
- [ ] Ошибка: нельзя сохранить контакт с папкой из другой сферы (например папка «Рабочее», а сфера «Личное») — показывается ошибка, а не «500».
- [ ] Ошибка: невалидная сфера (не Личное/Рабочее/Спам) отклоняется с понятным сообщением (422), не «500».
- [ ] Касание «Спам» на контакте — контакт переходит в сферу Спам; снятие **возвращает прежнюю сферу** (Личное/Рабочее), а не принудительно «Личное».
- [ ] Контакт без сферы, помеченный спамом и «раскрученный» обратно — снова без сферы (не теряет данные).
- [ ] В списке контактов виден бейдж классификации (Личное / Рабочее / Спам) и выбранные папки.
- [ ] Сортировка/фильтр по сфере и по типу работает.
- [ ] Контакт без сферы (старые данные) виден в списках и не теряется при фильтре «не спам».

## 6. Контакты (прочее)

- [ ] Заметки к контакту сохраняются и редактируются.
- [ ] День рождения можно указать — появляется событие в календаре.
- [ ] Контакт можно пометить важным (избранное).
- [ ] Поиск контактов по имени/телеграму/почте работает.
- [ ] Объединение дублей (мерж) работает: выбрать два похожих контакта, объединить.
- [ ] «Удалить и заблокировать» — после этого новые сообщения от контакта не приходят.

## 7. Дашборд

- [ ] Дашборд открывается со статистикой: непрочитанные, всего сообщений, контакты, задачи.
- [ ] Фильтры на дашборде (по сфере/типу) не «теряют» контакты без сферы.

## 8. Задачи, календарь, напоминания

- [ ] Задача создаётся (заголовок, дата, статус, приоритет).
- [ ] Повторяемая задача (повтор) создаётся один раз и видна повторяющимися в нужные дни.
- [ ] Календарь показывает события и задачи с датами.
- [ ] Напоминание о задаче приходит/показывается (локально в приложении).
- [ ] Невалидный статус задачи отклоняется понятным сообщением (422).

## 9. Настройки

- [ ] Страница «Настройки» открывается.
- [ ] Тема (светлая/тёмная) переключается и сохраняется.
- [ ] Интрервал опроса Telegram/Email можно изменить и он сохраняется.
- [ ] Файл `.env` рядом с exe создан и содержит сгенерированные SECRET_KEY/ENCRYPTION_KEY (production).

## 10. Экспорт/импорт/бэкап

- [ ] Экспорт контактов в CSV работает.
- [ ] Импорт контактов из CSV работает; битый CSV отклоняется с понятной ошибкой.
- [ ] Бэкап можно скачать (зашифрованный файл).
- [ ] Восстановление из бэкапа возвращает данные.

## 11. Завершение

- [ ] Выход через трей («Выход») полностью останавливает приложение (порт 7910 освобождается).
- [ ] При повторном запуске данные на месте (БД, контакты, настройки каналов).
- [ ] В папке рядом с exe появился лог `data\logs\bizibox.log`, в нём нет ошибок уровня ERROR.

---

## Если что-то упало

- Зафиксируйте: пункт чек-листа, что делали, что увидели (текст ошибки / скриншот).
- Посмотрите `data\logs\bizibox.log` рядом с exe — там видно причину.
- Приложите этот фрагмент лога к обращению.
